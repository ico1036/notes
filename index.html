Notes on Autonomous Research Loops

Working notes on research systems that run themselves — forming their own hypotheses, testing them against data, and writing down why each one failed. Mostly about the parts that are not the model.

Rule 110, seeded at random on every load. The rule is fixed and the seed is not, which is the whole subject of Deterministic and Probabilistic.

Harness principles

Five principles I settled on while building a quant research harness — an agent loop that proposes strategies, backtests them, and decides what it learned. Each one is written against the code rather than from memory, and each carries at least one thing it does not cover.

  1. 2026-08-10 · Harness principles Deterministic and Probabilistic

    Everything that can be a script should be a script. In this loop, zero of the fifty-eight files that run the pipeline call a model — and the one gate that claims to make a judgment it does not make is the most interesting thing in the codebase.

    agent design · gates · the honest failure

  2. 2026-08-10 · Harness principles Fat Skill, Thin Multi-Agents

    Two thousand lines of procedure against eighty-five lines of orchestration. Fanning out ten drafts sounds like ten bets and is often one bet written ten ways — the orthogonality is enforced by a syntax check that a competent fan-out can satisfy while producing copies.

    skills · multi-agent · information hiding

  3. 2026-08-10 · Harness principles Overfit and Dynamic

    Markets move and are trivially easy to overfit. The anti-convergence mechanism here is borrowed from slime mould: a trail that evaporates and a forced jump to cold ground. It works, and it cannot tell a dead idea from a changed world.

    search · stigmergy · nonstationarity

  4. 2026-08-10 · Harness principles Abstraction Layer, but Think First

    Raising the coordinate system is how a loop stops starting from zero. But a language model will assert a shared structure between any two findings you put in front of it, and nothing in this repository checks whether that structure is real. Grep the commit path for the word: zero matches.

    ontology · falsifiers · what is not enforced

  5. 2026-08-10 · Harness principles Look-Ahead Bias and Path Dependency

    A backtest leaks the future through channels no amount of care inside the strategy can close. You close them from outside, by running the same code over shifted windows and demanding the weights be identical. The first version of that check passed a strategy that was cheating.

    backtesting · integrity · blind spots
